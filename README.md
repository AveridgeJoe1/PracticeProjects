# README.md

## Practice Repo (Oct 25 2026)

The main purpose of this repo is to do periodic practice of various information technology techniques I want to be more familar with. I am starting on Oct 25 2026. 

Claude constructed a review guide/project ideas all the way from how to web works and HTML to the theory of computation and everything in between. 

I am going to follow it loosely, and may change some pieces in the future, depending on if I find something I would like to focus deeper on. 

First, I run through principal/knowledge reviews. 
Then, I review the tools used in each subject area for investigation/development/building.
Finally, I create a piece of work that reflect this knowledge. Either a build/repo, a Technical write-up of findings/code, or both. 

### Rules: 

 - For each concept I am starting from the earliest point possible
 - I can ask AI for help, explanations of concepts/where to find things,or identify error logs, but I have to make the solutions manually 
 - google search and look at documentation or examples, try to avoid direct AI solutions as much as possible
 

### Rationale

In the real world, of course I would be using the best and most advanced tools availible to me in order to meet organizational objectives. However, I would like to make sure that I do not let my own skills dull and become over reliant on AI solutions. 
This is an attempt to keep learning and reviewing the field in order to improve myself.
